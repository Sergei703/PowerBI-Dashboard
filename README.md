# 🏥 Hospital ER Dashboard (Power BI)

Интерактивный дашборд в Power BI для анализа работы отделения неотложной помощи (ER) больницы: нагрузка, время ожидания, удовлетворённость пациентов и распределение обращений по отделениям.

![Hospital ER Dashboard](dashboard.png)

## 📌 О проекте

Проект отвечает на практические вопросы руководства отделения:

- Сколько пациентов поступает ежедневно и как меняется нагрузка по месяцам?
- Как долго пациенты ждут помощи и как часто помощь оказывается вовремя?
- Насколько пациенты довольны сервисом?
- Какие отделения и возрастные группы создают основную нагрузку?
- Какая доля пациентов приходит без направления?

## 🧱 Модель данных

| Таблица | Назначение |
|---|---|
| `My_Hospital_ER_Data` | Таблица фактов: одно обращение — одна строка |
| `Календарь` | Таблица дат (помечена как таблица дат) |

**Связь:** `Календарь[Date]` → `My_Hospital_ER_Data[Patient Admission Date]`, «один ко многим», фильтрация в одну сторону.

**Календарь на DAX:**

```dax
Календарь =
ADDCOLUMNS(
    CALENDAR(DATE(2023,4,1), DATE(2024,10,31)),
    "Год", YEAR([Date]),
    "Номер месяца", MONTH([Date]),
    "Месяц", FORMAT([Date], "MMMM", "ru-RU"),
    "Год-Месяц", FORMAT([Date], "YYYY-MM")
)
```

Столбец «Месяц» отсортирован по «Номеру месяца», чтобы месяцы шли в календарном порядке, а не по алфавиту.

## 📐 Меры DAX

```dax
Обращений = COUNTROWS('My_Hospital_ER_Data')

Среднее ожидание, мин = AVERAGE('My_Hospital_ER_Data'[Patient Waittime])

Средняя оценка сервиса = AVERAGE('My_Hospital_ER_Data'[Patient Satisfaction Score])

% с задержкой =
DIVIDE(
    CALCULATE(COUNTROWS('My_Hospital_ER_Data'), 'My_Hospital_ER_Data'[Своевременность] = "Delay"),
    [Обращений]
)

% без направления =
DIVIDE(
    CALCULATE(COUNTROWS('My_Hospital_ER_Data'), 'My_Hospital_ER_Data'[Department Referral] = "None"),
    [Обращений]
)

% с оценкой сервиса =
DIVIDE(
    CALCULATE(COUNTROWS('My_Hospital_ER_Data'), NOT ISBLANK('My_Hospital_ER_Data'[Patient Satisfaction Score])),
    [Обращений]
)
```

> `Своевременность` — столбец со значениями `Delay` / `On-Time`. Если в вашей модели он называется иначе, замените название.

## 🖥 Что показывает дашборд

- **Карточки KPI**: число обращений, среднее ожидание, % с задержкой, % без направления;
- **Ежедневное количество пациентов**: динамика нагрузки;
- **Среднее время ожидания** по дням месяца;
- **Средняя оценка сервиса** по дням месяца;
- **Доля своевременного оказания помощи** (Delay / On-Time);
- **Распределение пациентов по полу**;
- **Количество пациентов по возрасту** (группы по 10 лет);
- **Количество пациентов по отделениям**.

Фильтрация выполняется срезами по **году** и **месяцу**; все визуалы страницы обновляются синхронно.

## 🔍 Основные наблюдения

- Около 59 % обращений обрабатываются с задержкой.
- Возрастные группы представлены примерно поровну (≈ 1 050–1 200 пациентов в каждой), то есть возраст не определяет нагрузку.
- Большинство пациентов (5 400) пришли без направления в профильное отделение; среди направленных лидируют *General Practice* (1 840) и *Orthopedics* (995).
- Оценка сервиса указана лишь у ≈ 27 % пациентов (2 517 из 9 216), поэтому выводы по удовлетворённости нужно делать с осторожностью.
